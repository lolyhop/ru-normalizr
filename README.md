# ru-normalizr

Форк [NickZaitsev/ru-normalizr](https://github.com/NickZaitsev/ru-normalizr) с правками под задачи TTS-нормализации в боте для ресторанных броней и Яндекс.Директ.

Приводит числа, даты, время, суммы и номера заказов к форме, пригодной для синтеза речи:

```python
from ru_normalizr import normalize

normalize("Ваш номер заказа 12345678")
# → "Ваш номер заказа один два три четыре пять шесть семь восемь"

normalize("Столик забронирован на 02.05 в 19:00")
# → "Столик забронирован на второго мая в девятнадцать ноль ноль"

normalize("Итого 3.50 рублей")
# → "Итого три рубля пятьдесят копеек"
```


## Использование

```python
from ru_normalizr import normalize, NormalizeOptions

# Режим tts — рекомендуется для синтеза речи
options = NormalizeOptions.tts()
result = normalize("Бронирование на 15 января в 19:00", options)
```

По умолчанию используется режим `safe` — нормализует числа, даты и время, но не трогает регистр и аббревиатуры. Режим `tts` дополнительно нормализует CAPS и раскрывает аббревиатуры.

## Что обрабатывается

### Даты

```python
normalize("02.05")          # → второго мая
normalize("02-05-2023")     # → второго мая две тысячи двадцать третьего года
normalize("15 января 2024") # → пятнадцатого января две тысячи двадцать четвёртого года
normalize("с 3 по 7 января") # → с третьего по седьмое января
```

### Время

```python
normalize("в 19:00")   # → в девятнадцать ноль ноль
normalize("в 6 30")    # → в шесть тридцать
normalize("в 7 00")    # → в семь ноль ноль
```

### Номера заказов и идентификаторы

Числа после слов `номер`, `заказ`, `заказа`, `артикул`, `код`, `инн`, `кпп` и др. читаются по цифрам:

```python
normalize("Ваш номер заказа 12345678")  # → один два три четыре пять шесть семь восемь
normalize("Заказ 1234 принят")          # → один два три четыре принят
normalize("Артикул 987654")             # → девять восемь семь шесть пять четыре
```

Суммы после этих же слов читаются нормально, если за числом идёт валюта:

```python
normalize("Сумма заказа 1500 рублей")  # → тысяча пятьсот рублей
```

### Деньги

```python
normalize("Стоимость 1500 руб.")      # → тысяча пятьсот рублей
normalize("Итого 3.50 рублей")        # → три рубля пятьдесят копеек
normalize("иметь 1000 долл.")         # → тысячу долларов
```

## Структура пайплайна

Нормализация проходит по стадиям по порядку:

| Стадия | Что делает |
|--------|------------|
| `preprocess` | Чистка пробелов, пунктуации, нумерованных списков |
| `roman` | Римские цифры |
| `years` | Годы и десятилетия |
| `dates_time` | Даты и время |
| `numerals` | Числа, дроби, единицы измерения, валюта |
| `abbreviations` | Аббревиатуры и сокращения |
| `latinization` | Латиница → кириллица |
| `finalize` | Финальная чистка |

Отдельные стадии доступны через `Normalizer.run_stage(stage, text)`.
